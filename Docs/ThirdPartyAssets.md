# Third-party art imported for the house pass

The free source files below were downloaded on 2026-11-03 and 2026-11-04 for the Godot 4.7.2 project. Poly Haven labels its models [CC0](https://polyhaven.com/license): game use and redistribution with a game are allowed, and attribution is optional. Credit is recorded here anyway. Poly Pizza labels the Quaternius model Public Domain (CC0) on its listing. The importer verifies every Poly Haven source file against the size and MD5 published by Poly Haven's public API; each asset's `source.json` records the exact download URL, hash, author and file count.

The active house web art uses original Blackweb generated textures plus procedural 3D silk, not the Poly Pizza cobweb mesh. All CC0 source art above lives under `Godot/assets/third_party/`; generated Blackweb art remains under `Godot/assets/generated/`. The 1K Poly Haven sources add about 12.31 MB before Godot's import cache. Static house props are one cabinet, one shelf and one caged ceiling fixture; the latter is a mesh only, aligned with an existing light. Their imported meshes do not cast dynamic shadows. A native rendered review on Intel HD Graphics 530 is saved locally under `Evidence/house-dressing-*.png`. The flashlight blows out the cabinet's white paint at close range. [Current same-GPU frame-time checks](Phase1RenderCheck.md) show the 1280 × 720 entrance remains slow and the optional 960 × 540 setting improves its median; these are spot checks, not a measured FPS change due to the art alone.

The user chose to pursue both free and Fab options. [Fab's own download guide](https://dev.epicgames.com/documentation/fab/purchasing-and-downloading-assets-in-fab) says even an anonymous free download requires accepting the applicable EULA; priced listings also use a license and purchase flow. The project brief prohibits the agent from accepting agreements. Consequently, no Fab source files were acquired. The [Mobility Starter animations](https://www.fab.com/listings/2c29cfb9-07c4-4e02-a466-5e7ef863633d), [openable kitchen cabinets](https://www.fab.com/listings/0a585e8a-361b-49a1-8cd7-287423e761a3), [animated rusty cabinet](https://www.fab.com/listings/32dc1961-8186-4b84-968d-45bc5bb16f2d), [realistic web](https://www.fab.com/listings/66a8f27f-38b9-4c52-8b45-0491fe4d2eb3), and [free tactical flashlight](https://www.fab.com/listings/e458eeda-2893-45b9-a946-a031ea395d96) remain reviewable candidates. Their displayed price and applicable license tier need checking at acquisition time. [Fab Standard License](https://www.fab.com/eula) permits use with compatible engines beyond Unreal when that is the license actually acquired.

Mixamo remains a free animation candidate, but its Adobe ID requirement and skeleton retargeting are outstanding. No external crouch or jump clips were added to Luke by this import.

## Game-only licensed spider candidate

[Literock Studios Giant Spider Lite](https://literock-studios.itch.io/giant-spider-lite) was acquired from the creator's itch.io listing on 2026-11-04 as the official 31 MB ZIP (SHA-256 `AAA5EBA63507E0CAF79DE3D18E5E13DEEBB973635ADA89EDD518D151B4438AB5`). The listing describes a 9,974-triangle, 49-bone GLB with 2K PBR textures and idle, walk, run and bite clips. The actual Godot import has **46 bones**, one skinned mesh, and all four named clips; the difference from the creator's advertised bone count has not been explained and does not by itself establish an animation fault. The included `LICENSE` permits use compiled or packaged inside a game, while forbidding standalone or raw-asset redistribution. The active local playable uses a derived 1K GLB under `Godot/assets/third_party/literock/` for the visible sighting and two combat juveniles. Its raw asset directory is excluded from the private GitHub source repository; that checkout uses the CC0 Quaternius fallback. The 1K model passed rig, bite, doorway visibility and native-render checks. See [LiterockSpider.md](LiterockSpider.md) for the measured model and frame-time tradeoff.

None of the Fab spider candidates was acquired. For human item actions, the [Fab Survival Set](https://www.fab.com/listings/b5d3902f-9406-44e3-97c9-42b739cf8a0f) advertises flashlight and eating clips in FBX on the Epic skeleton; the [First Person Knife Animation Set](https://www.fab.com/listings/0beb58c4-f42d-459b-a745-cd96dbcf7770) advertises slashes but says retargeting setup is not included and its listing provides Unreal format only. Both require license review and retargeting. The current flashlight, knife and candy actions therefore use project-authored motion rather than external clips.
