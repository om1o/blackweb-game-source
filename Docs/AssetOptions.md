# Asset options for the next Blackweb pass

The current playable uses Godot 4.7.2. The user chose both the free and Fab directions. A small set of verified CC0 sources is now imported for review; [ThirdPartyAssets.md](ThirdPartyAssets.md) records exact files and use. Fab and Mixamo remain candidates because their acquisition involves EULA acceptance or an account. Use GLB/glTF where available; FBX animation clips need import and retargeting. Each Fab listing's actual license and price must be checked at acquisition time.

[Fab's Standard License](https://www.fab.com/eula) can cover use outside Unreal, but each acquisition needs its actual applicable license checked; [older Unreal Marketplace assets may retain different terms](https://dev.epicgames.com/documentation/fab/purchasing-and-downloading-assets-in-fab). Fab says even anonymous free downloads require accepting an applicable EULA, so no Fab file was acquired under the existing no-agreement instruction. Godot documents [GLB/glTF scene import](https://docs.godotengine.org/en/4.0/tutorials/assets_pipeline/importing_scenes.html) and [humanoid retargeting](https://docs.godotengine.org/en/4.3/tutorials/assets_pipeline/retargeting_3d_skeletons.html).

For the lag and five-gigabyte target, start with 1K textures, instance or reuse meshes, avoid extra real-time shadow casters, and profile the actual target GPU before keeping an asset. The existing code-native crouch and jump controls, opening storage, and procedural webs do not depend on these downloads.

The starter quick items are now fixed as the weak flashlight, worn knife, and candy bar. Dedicated crouch and jump clips remain absent. The Fab candidates are ready for later user-side license and acquisition decisions; this milestone does not depend on them.
