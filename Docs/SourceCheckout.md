# Private source checkout

This GitHub repository is a source mirror for the Blackweb house tutorial. It is **not a standalone game download**. The complete, tested local workspace includes supplied game content whose separate redistribution terms were not provided, so the repository omits it.

The repository contains authored Godot gameplay, UI, scene-building code, data, tests, tooling, and documentation. It also includes the original Blackweb web and residue PNGs and Kokoro-generated line, CC0 Poly Haven and Quaternius assets, and MIT-licensed Microsoft Rocketbox character files with their retained notices. The separately acquired Literock Giant Spider Lite model is excluded because its license allows packaged-game use but forbids raw-asset redistribution. Sources and obligations are documented in [ThirdPartyAssets.md](ThirdPartyAssets.md), [LukeAsset.md](LukeAsset.md), and [WebAndVoicePass.md](WebAndVoicePass.md).

To reproduce the playable local workspace, the user must supply their own authorized original game files and local recovery outputs under `RecoveredAssets/`, restore the private `Godot/data/opening_components.json` capture, and provide Godot 4.7.2 under `Godot/runtime/` (or adapt the helper path to an installed Godot). The local project also has generated `Godot/scenes/recovered_house.tscn` and `Godot/scenes/spider_visual.tscn`; these embed recovered geometry and are omitted from GitHub. With those source inputs in place, `Tools/BuildGodot.ps1 -Action RecoverScene` rebuilds the house scene, and `Godot/tools/build_spider.gd` rebuilds the spider visual after the Godot import. The repository does not bundle the original game, its asset mapping binaries, a Windows runtime, a PCK, or saved game data.

The reported gameplay and portable tests were run against the **complete local workspace**, before the GitHub source-only copy. They do not establish that a bare clone launches without the omitted local dependencies. Asset permission was confirmed by the user for this project; the original game's detailed redistribution terms remain unverified in [ASSET_PROVENANCE.md](ASSET_PROVENANCE.md).
