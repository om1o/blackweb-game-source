- https://raw.githubusercontent.com/google/fonts/main/ofl/barlow/Barlow-Regular.ttf
- https://raw.githubusercontent.com/google/fonts/main/ofl/barlow/Barlow-Medium.ttf

- https://raw.githubusercontent.com/google/fonts/main/ofl/barlow/OFL.txt

Barlow Regular/Medium is used for body copy and controls. Barlow Condensed
SemiBold is used for titles and section headings. Runtime code loads the
bundled font bytes directly, so first-run font availability does not depend on
Windows fonts, network access, or an editor import.
