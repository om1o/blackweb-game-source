# Original web mesh masters

SCENE: three original static silk treatments; authored in metres in hosted Blender 5.2; runtime GLB plus editable Blender source; 960 px inspection frames.

HIERARCHY: WebRadialTorn, WebSaggingCanopy, WebFurnitureCocoon roots; named structural and fine-strand meshes beneath each; separate studio camera/light rig removed from runtime GLB.

ASSETS: all original procedural geometry. Radial wall web around 2.4 m wide with broken spiral sectors, radial supports and loose anchor ends. Canopy about 2.7 x 1.9 m with gravity sag, uneven thread density and open tears. Cocoon wraps an irregular furniture volume about 1.3 x 1.0 x 1.0 m with overlapping strands and open gaps. No alpha cards, external models, recovered artwork, collisions or runtime lights.

SHOT: oblique orthographic overview plus focused front/side views to expose sag and volume; dark neutral background; no background asset falsely presented as game content.

LOOK: rough dusty grey-ivory silk, opaque plain Principled material exported to glTF. Fine strands intentionally thicker than real spider silk for game-distance readability; no photoreal/AAA claim.

LIGHTING: upper-left soft point key, restrained opposite fill, low ambient. Source studio only.

MOTION: static. Roots may be placed/scaled by the game; no physics simulation or baked animation.

ACCEPTANCE: three visibly distinct silhouettes, asymmetric connected strands with deliberate tears, dimensional report and local origin contract, fewer than 25,000 total triangles, clean named GLB roots, no alpha materials, successful Godot import and measured bounds. Visual judgement remains separate from successful code execution.
